# Contributing

session-glance is maintained by one person and developed in a private
repository; this repository is a published copy.

- **Bugs and ideas:** open an
  [issue](https://github.com/mfal/session-glance/issues/new/choose).
- **Pull requests:** not accepted. Describe the change in an issue instead.
- **Forks:** welcome under the terms of the [MIT license](LICENSE).

For a bug, the Claude Code version (`claude --version`), the surface (desktop
app, terminal, VS Code) and what the pane showed are usually enough to
reproduce it.
